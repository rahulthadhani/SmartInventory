# SmartInventory

AI-powered inventory management system using barcode scanning, OCR, and LLM description generation.

## Requirements

- Python 3.13
- OpenAI API key

## Setup

**1. Install dependencies**
```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

Then open your browser and go to:
```
http://127.0.0.1:5000
```
